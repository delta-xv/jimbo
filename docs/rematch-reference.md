# 对局规则基准

本项目对应 Junak 重赛：同一对手，一局三轮，每轮三回合，共九回合；每轮第三回合随机一种负面效果。随机负面效果是原作重赛机制。首次任务中的固定效果脚本不作为重赛流程。

第一至第八回合结束后进入商店，第九回合成功后结束整局。金币与小丑跨回合保留。回合得分、行动次数和回合限制在新回合初始化；本轮已出牌记录在下一轮重置；超新星的牌型计数跨轮保留，新开一局才清零。

## 默认基础目标

| 轮 | 第一回合 | 第二回合 | 第三回合 |
| --- | ---: | ---: | ---: |
| 第一轮 | 300 | 450 | 600 |
| 第二轮 | 2,000 | 3,000 | 4,000 |
| 第三轮 | 10,000 | 15,000 | 20,000 |

可在开局设置九个基础目标。“目标提高”把对应目标乘以 1.5，因此默认最终回合可能为 30,000；仅一次出牌将基础目标乘以 0.5，单一牌型乘以 0.75。分数表的证据与尚未核实项见 [原作核对](parity-reference.md)。

## 随机负面效果

| 效果 | 实现语义 |
| --- | --- |
| 无法弃牌 | 本回合弃牌次数为 0 |
| 一手定胜负 | 本回合仅一次出牌机会，目标 ×0.5 |
| 手牌缩减 | 手牌上限减少一张，与小丑被动规则共同计算 |
| 人头牌失效 | 人头牌仍参与牌型，不提供单牌筹码和单牌效果；幻视改变的人头牌身份同样适用 |
| 单一牌型 | 首次出牌锁定本回合可用牌型，其他牌型无法提交，目标 ×0.75 |
| 不许重复 | 本回合已使用的牌型无法再次提交 |
| 强制选牌 | 随机锁定一张手牌，出牌与弃牌必须包含它，补牌后重新选择 |
| 随机小丑失效 | 一张小丑失效，出牌后重新抽取；暂停计分、牌型修改与自身成长；快乐安迪的固定弃牌额度和手牌上限保持生效 |
| 目标提高 | 本回合目标乘以 1.5 |
| 已打出牌失效 | 本轮此前打出的牌按花色与点数识别，在该回合不提供单牌筹码和单牌效果；弃牌不计入已打出记录 |

效果仅作用于对应第三回合，离开后清除。从候选池无放回抽取，一局内三种效果不重复。负面效果、牌库、商店、卡包、小丑随机能力使用独立随机过程。精确候选池、权重及少数效果边界仍须原作数据确认。

## 验证

33 张小丑及三种卡包可用。默认种子 1 的完整通关动作位于 `tests/fixtures/winning-run.json`，最终回合累计 32,718 分。该记录验证流程可完成，不代表全部种子已完成胜率评估。利息、计分集合、失效状态、基础预览及跨回合恢复均有测试。
