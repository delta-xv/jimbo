# Junak 重赛规则与证据

对局基准为《潜水员戴夫》中再次挑战 Junak 的重赛：同一对手，一局三轮，每轮三回合，每轮第三回合随机负面效果。随机负面效果属于原作机制；界面不使用更换 Boss 或切换对手的概念。首次任务的固定效果脚本仅用来核对共用卡牌说明，不用来替代重赛的随机流程。

## 重赛目标曲线

[完整重赛录像](https://www.bilibili.com/video/BV1nLUAYgEkD/)在开局显示下注与历史最高分，可确认属于任务完成后的重赛。以下为逐帧观察到的实际目标：

| 位置 | 实际目标 | 证据 |
| --- | --- | --- |
| 第一轮三个回合 | 300 / 450 / 600（无法弃牌） | [06:31 的回合列表](https://www.bilibili.com/video/BV1nLUAYgEkD/?t=391) |
| 第二轮三个回合 | 2,000 / 3,000 / 3,000（单一牌型） | [11:50 的回合列表](https://www.bilibili.com/video/BV1nLUAYgEkD/?t=710) |
| 第二轮另一负面效果 | 2,000 / 3,000 / 2,000（仅一次出牌） | [另一段重赛录像 03:02](https://www.bilibili.com/video/BV1gJPazeETs/?t=182) |
| 第三轮第一回合 | 10,000 | [14:07](https://www.bilibili.com/video/BV1nLUAYgEkD/?t=847) |
| 第三轮第二回合 | 15,000 | [16:39](https://www.bilibili.com/video/BV1nLUAYgEkD/?t=999) |
| 第三轮第三回合 | 20,000（强制选牌） | [16:56](https://www.bilibili.com/video/BV1nLUAYgEkD/?t=1016) |

基础目标采用 300/450/600、2000/3000/4000、10000/15000/20000。负面效果按基础目标折算：目标提高 ×1.5、仅一次出牌 ×0.5、单一牌型 ×0.75，其余 ×1。

证据边界：第二轮第三个基础值 4,000 是统一倍率模型中的参数；实机直接核实的是相应负面效果下的 3,000 与 2,000。将倍率扩展至另外两轮属于实现推导，尚未逐种效果、逐轮穷举实机。该模型与上述已观察场景一致，不将推导参数写成直接读取的原作数据。

## 已定稿的实现规则与证据边界

以下项目已有可执行规则与测试，但公开资料不足以证明它们与原作每个细节完全相同。

| 项目 | 当前采用 | 证据边界 |
| --- | --- | --- |
| 九回合目标 | 按上表基础值与负面效果倍率计算 | 实机观察与推导边界见上节 |
| 小丑抽取比例 | 从未持有的牌种中等概率抽取，每次在剩余候选池中均匀选择 | 本项目采用的概率约定，稀有度只用于展示 |
| 卡包抽取比例 | 默认三种规格 1:1:1 | 原始权重未确认；可在开局设置调整 |
| 负面效果抽取 | 十种候选中等概率无放回抽取三种，一局不重复 | 按项目约定定稿；原作精确权重与候选范围仍未完整验证 |
| 随机小丑失效 | 回合开始选一张，出牌结算后重新选；弃牌和排序不重选 | 中文重赛攻略确认存在该效果，详细抽取时点采用当前明确约定；尚缺对应实机连续过程 |
| 同名小丑与去重 | 每种最多持有一张；明牌和卡包排除已持有牌；付费刷新额外排除上一批商品牌种，包括已售槽 | 本项目约定；原作完整去重范围未确认 |
| 超新星 | $5；整局牌型次数 ×3，包含本次及获得此牌前的出牌，新开一局清零 | 整局累计规则已确认；计数不受跨轮、购买或卖出此牌影响 |
| 印错小丑 | +0–23，出牌后揭晓随机值 | 采用 0–23 作为确定规则；戴夫原始上界尚无直接证据 |
| 照片 | 首张计分人头牌 ×2，每实例每次出牌仅一次；属于单牌阶段 | 按 Wiki 描述；与重复触发的精确边界仍需原作对照 |
| 蓝图 | 复制右侧计分与重复触发能力，不能复制蓝图；不复制被动规则 | 按事件类别定稿；复制目标的现有成长值，不重复增加成长，详情显示兼容性；不宣称该表来自原作内部数据 |

不能将单一攻略与 Wiki 的冲突直接当作应修改代码的依据。已由实机澄清的半张小丑和花色小丑采用实机说明；小丑牌采用明确的等概率约定，卡包出现比例保留为可调整参数。

## 信息展示与结算范围

选牌阶段仅显示牌型基础筹码和倍率，实际分数与随机结果在出牌后揭晓。牌库详情按固定顺序标记待抽、手中和已用牌，不显示抽牌顺序。局外鲛人币下注不纳入本项目，仅保留每局胜负。
