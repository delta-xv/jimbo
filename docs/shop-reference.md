# 商店规则来源

本项目的商店结构参考《潜水员戴夫》Jimbo 游戏，使用资料列出的 33 张小丑牌目录。

| 规则 | 实现 | 依据 |
| --- | --- | --- |
| 货架 | 两张明牌和一个随机小丑卡包 | [Dave the Diver Wiki：Store](https://dave-the-diver.fandom.com/wiki/Jimbo%27s_Game#Store)、[玩家商店说明](https://www.reddit.com/r/DavetheDiverOfficial/comments/1gq42mv/jimbos_game_interest_and_using_won_joker_cards/) |
| 刷新 | 只替换两张明牌；卡包不参与刷新 | 同上 |
| 刷新价格 | 每次商店从 $1 起，每次增加 $1 | [玩家对 Jimbo 与 Balatro 的比较](https://www.reddit.com/r/DavetheDiverOfficial/comments/1gw068z/)，Wiki 确认逐次涨价 |
| Buffoon Pack／小丑卡包 | $4，随机 2 张选 1 | Wiki 的卡包表 |
| Jumbo Buffoon Pack／巨型小丑卡包 | $6，随机 3 张选 1 | Wiki 的卡包表 |
| Mega Buffoon Pack／超级小丑卡包 | $8，随机 4 张选 2 | Wiki 的卡包表 |

资料为社区 Wiki 和玩家描述。卡包中文名称沿用 Balatro 常用译名；尚未用戴夫简体中文界面逐字核对。

## 当前适配

- 三个包型默认等概率出现，包型比例可在开局设置。明牌和包内候选从 33 张小丑牌中等概率无放回抽取；付费刷新排除上一批两张商品的牌种（包括已售槽），明牌与卡包候选均排除已持有的牌种；每种小丑最多持有一张。小丑等概率与刷新去重采用本项目约定；原作包型概率尚未核实。
- 购买后揭示候选，选择免费。不同规格价格分别为 $4／$6／$8，未查到同规格随机变价的可靠证据。封面与规格绑定。每次商店的卡包仅购买一次，刷新不会补充已售卡包。
- 允许放弃剩余选择且不退款。槽位满时允许付费购买并揭示卡包，领取候选时须有空位；选择期间允许出售旧牌。候选与剩余次数在售卖、排序和读档后保持不变。以上边界按当前交互实现，不宣称已逐项确认原作行为。
- 开包期间须完成选择或放弃剩余选择，再返回明牌货架；不能跳过该流程直接进入下一回合。
- 牌库、明牌、卡包、负面效果各使用独立随机过程，刷新和开包不改变后续发牌。
- 利息已实现；回合奖励为基础奖励（3／3／5）加剩余出牌与利息。
