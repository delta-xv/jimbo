# 动效参考与实现范围

参考 [GBALATRO/balatro-gba](https://github.com/GBALATRO/balatro-gba) 的表现方式，用 React、CSS 动画和 Web Animations API 适配当前网页。视觉部分未复制其 GBA 代码或贴图；不承诺逐帧一致。

| 参考场景 | 当前表现 | 参考实现 |
| --- | --- | --- |
| 选牌与整理手牌 | 选中抬升、高亮、取消回落；排序按钮触发平滑换位 | `source/game/round.c`、`source/item.c` |
| 发牌与补牌 | 新牌从牌堆方向依次入场，牌堆轻微抖动 | `source/game/round.c` 的 draw 流程 |
| 出牌 | 选中牌向桌面移动，桌面牌组入场 | 同上 play 流程 |
| 弃牌 | 选中牌向右下旋转退场，随后补牌 | 同上 discard 流程 |
| 逐张计分 | 计分牌弹跳、加筹码浮字；不计分牌变暗，失效牌短暂抖动 | 同上 card scoring 流程 |
| 小丑触发 | 按实例逐张弹跳高亮，依照真实 Chips／Mult／×Mult 步骤更新数字 | 同上 Joker scoring 流程 |
| 分数反馈 | 筹码、倍率弹跳，总分递增并入账；本手分数达到回合目标时显示蓝红火焰 | `toggle_flaming_score`、score lerp 流程 |
| 回合结算 | 面板弹出、奖励逐行出现、金币递增、过关粒子散开 | `source/game/round_end.c` |
| 胜利／失败 | 独立全屏 YOU WIN!／GAME OVER，标题短入场与一次性装饰动画，不显示分数或奖励 | `source/game/game_over.c` 的面板进场 |
| 商店 | 面板滑入、灯带流动、刷新换牌、已购盖章、持有牌入场 | `source/game/shop.c` |
| 售卖 | 旧小丑旋转退出，卖价浮字，剩余卡槽平滑移动 | `source/game/joker_row.c` |
| 开包 | 候选牌错峰翻开，选中后反馈；沿用当前卡包规则 | 适配当前商店流程 |
| 轮次／负面效果 提示与详情 | 提示滑入，详情对话框弹入 | `source/game/blind_select.c`、`source/game/shop.c` |
| 牌桌背景 | 低幅度、缓慢旋转缩放的纹理流动 | 背景氛围适配 |

## 播放与规则

游戏引擎一次性提交结果；视觉层按「离手 → 各计分步骤 → 总分入账 → 补牌」播放，动画本身不加分、不扣款、不生成随机数。计分明细保留触发小丑的实例 ID，蓝图复制和原牌触发分别高亮对应实例。

标准模式每个计分步骤 240 毫秒，快速模式使用 45% 时长。即时模式和系统减少动态效果设置均关闭过渡、火焰、背景流动、数字递增与位移动画，并在 30 毫秒内释放视觉锁。出牌、弃牌和发牌期间阻止重复动作；组件卸载清理定时器与动画帧。

选牌界面只显示当前牌型，历史结果仍在计分明细中查看。小丑牌支持鼠标与触屏拖动插入排序，移动超过 7px 后显示牌影和位置预览，松手后提交顺序；拖出牌区、取消触摸、按 Escape 或切入后台时取消。点击仍打开详情，左右移动按钮保留；发牌、计分与提示动画期间不能拖动。手牌保持点选与按钮排序。计分播放时临时收起桌面 Boss 横条，为计分牌和浮字留出空间；结算结束后恢复。

## 尚无对应功能的效果

当前尚无消耗牌、增强／特殊版本、可消耗或销毁的小丑、可跳过盲注选择和完整失败统计页，因此未引入这些系统专属的变换、销毁与面板切换效果。喜剧演员、喜与悲和蓝图引发的额外触发会生成独立计分步骤，沿用牌面弹跳、小丑高亮和浮字。音频与计分阶段同步，范围见 [音乐与音效](audio.md)。GBA 固定分辨率的逐像素位移和特定着色方式以适合桌面与手机的网页效果近似。

整局胜利动画为 1.2 秒，失败为 0.8 秒；快速设置按 45% 时长播放，即时与减少动态效果设置直接显示结果和按钮。点按、Escape 或 Android 返回键可跳过入场；结束后返回键回到主菜单。最终结果不显示侧栏、牌桌、分数或奖励明细，支持直接用当前规则生成新种子再来一局。前八回合仍保留奖励结算与进入商店。

## 累计效果反馈

城堡、方形小丑、绿色小丑与超新星在有效出牌／弃牌改变累计效果时反馈一次：增益使用青绿色亮边与轻弹，减益使用红橙色边缘、短暂压暗与轻微收缩震动，不显示浮字或新增数值标签。标准模式时长分别为 540ms 和 440ms，快速模式按 45% 播放；即时与减少动态效果设置下不播放。

反馈从本次操作前后的真实数值变化产生，不改动规则、随机状态或现有操作等待时间。绿色小丑降到零后不会继续触发减益；城堡未匹配目标花色、失效牌和无效操作不触发对应动效。超新星只比较本次牌型的历史次数，切换牌型不会误报下降。读档、排序、购买和进入新回合不重播累计动效；印错小丑等随机变化不计作累计成长。

累计动效与计分触发高亮独立播放，结束后回到原始外观，连续操作可再次触发。动画事件不写入存档。
